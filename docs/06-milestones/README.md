## Rules

1. Edit the template in place on your branch. Do not rename it.
2. Keep all five headings - `What I built`, `How to run it`, `Evidence`,
   `Metrics`, `Known gaps`. CI fails a submitted report that drops one.
3. Delete the `_Not started_` line when you begin. CI treats a report still
   carrying that line as a blank template and skips it.
4. Never paste real patient data into a report or a screenshot.
