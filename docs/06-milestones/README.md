# Milestone reports

One report per milestone, on your own branch. This is what gets graded.

| Report | Weeks | Theme | Due |
|--------|-------|-------|-----|
| [milestone-1.md](milestone-1.md) | 1-2 | Project initialization, design and core setup | End of week 2 |
| [milestone-2.md](milestone-2.md) | 3-4 | Risk prediction and readmission forecasting | End of week 4 |
| [milestone-3.md](milestone-3.md) | 5-6 | Treatment effectiveness and healthcare analytics | End of week 6 |
| [milestone-4.md](milestone-4.md) | 7-8 | Testing, deployment and documentation | End of week 8 |

## Rules

1. Edit the template in place on your branch. Do not rename it.
2. Keep all five headings - `What I built`, `How to run it`, `Evidence`,
   `Metrics`, `Known gaps`. CI fails a submitted report that drops one.
3. Delete the `_Not started_` line when you begin. CI treats a report still
   carrying that line as a blank template and skips it.
4. Never paste real patient data into a report or a screenshot.
